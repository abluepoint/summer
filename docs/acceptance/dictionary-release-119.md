关联 [任务 #119](https://github.com/abluepoint/summer/issues/119)、父方案 #108，用户故事 7、8、9、49、50；前置 #117 已完成。原票七项验收逐条通过，结构化记录见 [dictionary-release-119-result.json](dictionary-release-119-result.json)。

## 实现与修复

字典使用不可变发布快照；草稿编辑不会进入公开读取。发布、停用、回滚经真实 HTTP 完成，MySQL 持久化版本、审计和 outbox，实际 Redis 缓存随版本变更失效。双 JVM 对同一预期版本竞争只有一个成功，另一个收到 409，重启后历史仍保留。本轮无需修改后端。

实际 Chrome 先发现：字典停用后的 404 会清空尚未提交的覆盖 JSON，恢复版本后也不能找回。修复仅调整字典页面失败处理：404 清除失效选择、选项和版本，保留用户编辑的覆盖 JSON；401/403 仍清除消费者及表单状态。保留原有租户、单项校验和通知逻辑。
