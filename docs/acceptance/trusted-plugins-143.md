## 设计与实现

Summer Sample 的 `customer-insights` 是应用随包交付、受信任目录登记的业务插件。它贯通客户数量读取、已发布参数与字典、企业菜单、持久权限、配置 DataScope 和审计。它不提供任意代码上传或任意前端组件装载。插件登记、摘要和版本兼容均由服务端校验；配置读取沿用 [ADR0028](../adr/0028-enforce-effective-configuration-scopes.md) 与 [ADR0031](../adr/0031-resolve-configuration-tenants-and-version-overrides.md) 的授权及覆盖优先级。

真实 Chrome 发现并修复两类界面问题：

1. 管理页读取失败后保留旧洞察，恢复成功后保留旧错误；重新加载仍显示过期兼容诊断。现在读取前清空洞察和错误，诊断前清空旧诊断和错误，重新加载清空两类结果。
2. 插件声明 `/plugins/customer-insights` 没有企业读者入口。现在注册独立的本地客户洞察页面，菜单能力为 `enterprise.plugins.customer-insights.read`，中英文标题齐备，前端 manifest 版本由 5 提升为 6。页面从当前活动企业取得上下文，先读取真实企业插件 manifest，核验固定插件 ID、可信状态、ENABLED、菜单路径及能力，再请求摘要。未启用、菜单不可见或请求失败均不保留旧数据；未知后缀路径明确拒绝。请求序号阻止已失效的异步结果回填。

主会话复核进一步指出管理页的迟到响应竞争：A 先发的旧 200 可在 B 后发的 403 清屏后回填。补充修复仅涉及管理页请求协调：洞察与诊断分别保留请求序号，刷新及生命周期操作提升共同失效代次，卸载使所有在途请求失效。旧结果、错误、列表加载状态和生命周期回调均须通过当前代次与存活检查才更新；管理页 JSX 渲染正文未变化。独立企业页、routes、manifest、locale 均保持此前验收摘要。

该入口不依赖 `platform.plugins.read/write`，组件引用只在前端本地源码中。共享 main、menu API、access、父路由匹配，以及后端授权、DataScope、审计和用户 CustomerController 均未修改。停用时企业入口仍可显示不可用提示，摘要数据被阻断；权限撤销后当前菜单由已有持久授权刷新机制移除。
