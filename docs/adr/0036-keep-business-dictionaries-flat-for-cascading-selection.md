# 业务字典保持扁平，级联采用跨字典联动

为保持业务字典主体结构简单，字典项保持扁平，级联选择通过不同字典之间的联动表达。字典组是同一字典内字典项的命名子集，同一项可加入多个组，组内排序与字典默认排序独立。

跨字典联动采用“上游字典项的值 → 下游字典组”的对应关系，下游选项及其顺序取自对应字典组。对应关系由业务页面配置并传入通用级联组件；字典管理只维护字典、字典项和字典组。调整联动对应关系需要修改页面配置。

这一选择省去了字典项树形结构及其层级约束，并复用已有字典组来限定下游选项。字典组随所属字典整体发布和回滚，版本边界见 [ADR 0037](0037-publish-dictionary-items-and-groups-as-one-version.md)。

字典组以所属字典内唯一的编码标识，页面通过“字典编码 + 组编码”引用，组名可经后续发布修改。字典组一经发布，编码不可修改，组不可删除，退出使用通过停用完成，避免组改名或日常维护破坏已有页面联动配置。
