# 字典项和全部字典组共用字典发布版本

为保证字典项与分组内容一致，每个业务字典以整体为单位发布版本。一个版本完整包含字典项的值、显示名称和说明、字典默认排序，以及全部字典组、组成员和组内排序；字典组不单独发布版本。

修改先进入草稿，发布后才影响该字典的发布内容。回滚选择一个完整的历史发布版本，字典项和全部字典组一起切换，不能分别选择不同版本。

本决策补充 [不可变字典快照决策](0027-versioned-dictionary-public-snapshots.md) 的内容边界，保留其发布并发控制、幂等及回滚选择原历史版本的语义。页面配置的跨字典联动映射不属于字典发布内容，见 [ADR 0036](0036-keep-business-dictionaries-flat-for-cascading-selection.md)。

详情展示默认按当前生效的发布版本将字典值转换为显示名称，普通业务记录无需为此绑定保存时的字典版本。发布改名后，旧记录使用新的显示名称；回滚后，按所选历史发布版本的名称显示。

字典项停用并发布后，详情名称转换仍可使用当前生效版本中该项的显示名称，供新选择的选项列表则排除停用项。名称转换和可选项读取因此具有不同的过滤语义：本决策补充字典快照ADR0027的详情转换场景，可选项读取继续过滤停用项，字典本身的可读性和租户访问边界不变。

字典项一旦发布，禁止修改其值或删除该项，退出可新选范围通过停用完成；显示名称、说明和排序仍可经新版本调整。从未发布过的草稿项允许删除。

业务组件和字典管理的默认视图均只使用当前生效的发布版本。管理端查看草稿和历史版本需要显式切换，页面采用页签切换，交互约定见 [业务字典设计记录](../specs/business-dictionary-design.md)。

字典草稿保存也进行版本冲突保护：保存时校验读取草稿时取得的修订号，过期保存被拒绝，阻止覆盖其他人已保存的修改。草稿修订号与发布版本号分开；发布时同时校验操作者已查看的草稿修订号和当前生效版本，任一不匹配都提示刷新并拒绝本次发布，确保发布的是操作者已查看过的内容。
