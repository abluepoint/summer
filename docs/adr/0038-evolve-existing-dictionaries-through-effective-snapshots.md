# 演进既有业务字典并统一生效读取边界

本次完善沿用 Summer Sample 的现有字典、字典项、不可变版本、组织覆盖、审计、缓存及通知。在现有聚合上增加说明、字典组与组成员、草稿修订号及曾发布依据，不创建第二套字典系统或通用跨字典关系模型；业务结构及整体发布决定见 ADR 0036、0037。

部分替代字典快照 ADR 0027 中“已发布但无快照时直接读取编辑行”的兼容例外：升级时受控物化原生效内容，运行时统一读取所选快照。普通 CRUD 不能再通过发布布尔值绕过专用版本操作；所有字典编辑入口接入聚合修订保护。这是为保证草稿隔离而有意收紧的旧写入契约，旧调用方需要迁移。

旧公开选项列表和单项有效性校验保留原义，详情通过新增名称解析能力读取当前生效版中的停用项。现有组织覆盖保持组织、租户、基础的优先级和独立版本，通过统一的生效投影与字典组组合；隐藏覆盖仍阻止回退，覆盖不能借用草稿项，分组不能扩大覆盖或授权范围。

新程序兼容读取旧快照，历史原文和原序号保留；不承诺旧程序能读取新快照格式。完整接口适配、迁移和测试要求见[业务字典技术规格](../specs/business-dictionary-spec.md)。上述技术方案由本次 to-spec 综合形成，业务设计基线及测试边界已经用户确认，功能尚未实施。
