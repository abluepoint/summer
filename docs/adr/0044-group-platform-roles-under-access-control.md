# ADR 0044：平台角色管理归入访问控制目录

- 日期：2026-11-21
- 2026-11-24 更新：侧边栏的目录、名称与排序由平台菜单管理配置。导航按客户端编码和当前授权读取菜单，平台与租户管理入口继续使用各自的页面地址。以下为原分组决定。

## 决策

将“权限与资源”目录更名为“访问控制”，涵盖角色授权、权限定义与受控资源，目录暂不显示图标。目录下依次显示“接口目录”“菜单管理”“权限管理”“平台角色管理”，各子项仍依据现有服务端资格展示。平台角色管理继续进入 `/platform/roles`，租户角色管理保持独立入口 `/roles`。

继续先校验域内菜单资格，再进行本地导航分组。目录仅组织已有可见入口，不新增授权资源；页面路由、全局菜单清单及平台/租户授权边界不变。

## 与既有决定的关系

替代 [ADR 0042](0042-separate-platform-and-tenant-management-entries.md) 中“角色管理保持独立”的平台部分，以及 [ADR 0043](0043-platform-only-permission-management.md) 延用的目录名称；其他管理入口与平台权限目录决定继续有效。
