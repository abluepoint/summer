# 页面配置字典级联（#197）

入口仍为 `/dictionary/form`。`summer-ui/src/pages/dictionary/index.tsx` 的 `cascadeLevels`
指定每一级字典编码及精确字符串到下级组编码的映射。参考配置使用 customer-segment、cascade-second、cascade-third；
管理员需先在管理页维护并发布这些字典与组。组顺序由字典发布内容决定，页面不重排。

`DictionaryCascade` 接受 `levels`、受控字符串数组 `values` 和 `onChange`。
第一级读取默认选项，其余级通过各自 `groups` 读取前一级值对应的组。
映射的 `1`、`01`、空格和大小写保持原字符串；只读取映射对象的自有属性。
没有映射不会把 undefined 当成默认组读取。

初始化由调用方提供旧值，不启动主动清理。停用项、未知项和读取状态沿用共享名称回显。
用户改选才逐级确认新组资格；保留仍可新选的值，清除已确认失效值及其更深层。
无映射或成功读取后组不可用，代表主动改选没有可用范围；加载、网络失败或拒绝仍保留值。
清空上游直接清空所有更深层。切换业务记录时，调用方应通过 React `key` 重建组件，取消上一记录的校验意图；本票实证为卸载/重挂载。
不要将同实例在校验中直接替换全部受控值视为已经验证的记录切换方式。租户或配置改变会丢弃旧校验意图。

原覆盖编辑仍是独立入口，保留组织目标、修订、保存错误和未保存保护。
级联选择同样加入当前页面的未保存保护。示例选择值只在内存演示，不新增业务持久化入口。

真实与受控验收以及已知回归失败均见执行目录 handoff.json；本指南不代表验证通过。
