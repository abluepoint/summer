# 运行中字典刷新（#198）

详情名称、普通选择和各级级联共用同一上下文的字典读取条目。同一租户上下文和字典的活动读取共享一条既有 SSE，最后一份读取兴趣解除后关闭；空值且未映射的级别不订阅。不同权限快照保持独立授权读取，只共享使用同一会话的通知传输，避免复制长连接阻塞后续读取。焦点恢复、既有通知、断线/resync 和手动刷新会重新读取当前有权内容，原生 EventSource 仍负责续传。网络断线触发重读，不能直接解释为已确认撤权。

发布、停用、回滚和覆盖发布通知仅携带原有失效元数据。覆盖草稿不发公共发布通知。通知的 version 保持基础字典发布指针；独立覆盖 publishedRevision 和 opaque effectiveToken 取自授权重读响应。publishedVersion 可回退，effectiveRevision 单调推进，草稿修订不参与公共身份。

刷新期间清理旧派生数据，失败和拒绝分别展示；保持挂载的受控组件保留调用方业务原值；全局路由重建仍遵循既有表单重置规则。切租户/身份或组范围时隔离迟到响应。新名称/选择接口直接读取当前生效SQL；旧公开选项仍使用版本缓存与 ConfigurationFallbackGuard。权限、数据范围、基础状态和覆盖检查在公开缓存/降级之前执行。撤权通过后续既有焦点重读或其他授权读取确认；不承诺在没有通知或重读触发时即时察觉服务端权限变化。

本票没有新增数据库迁移。升级仍遵循 [V39生效读取](business-dictionary-191-upgrade.md)、[V40草稿](business-dictionary-192-drafts.md)、[V41生效修订](business-dictionary-193-lifecycle.md) 和 [V42分组](business-dictionary-194-groups.md) 的备份/检查点。字典内容回滚不等于程序或生产数据库降级；不承诺旧二进制读取新格式。本票执行目录记录真实批次、失败和恢复证据，本文不代表已完成验收。
