# 全国行政区划代码获取方法

2026-11-24 核查。全国统一快照为 2025-12-31，覆盖省、地、县、乡四级。以下两个入口均为民政部网站自身使用的查询服务。本文记录当次可复现的调用方式，版本和参数来自发布页，更新数据时应重新核对。[国家地名信息库发布页](https://dmfw.mca.gov.cn/XzqhVersionPublish.html) · [民政部政务服务查询页](https://zwfw.mca.gov.cn/appsv2/xzqhcx/detail.html?searchStr=110000000000&searchType=2)

## 全国一次性取数

在国家地名信息库使用表单 POST 请求 `https://dmfw.mca.gov.cn/xzqh/getCodeList`。保持 `parentCode`、`placeCode`、`title`、`type` 四个筛选值为空；版本为发布页指定的 `Xzqh20251231`。页码从 1 开始。实测每页 1,000 条，前 41 页各 1,000 条，末页 935 条。下面的 Python 3 示例只使用标准库，在核对条数及代码唯一性后向标准输出写 JSON，保留接口的原始字段。[发布页面及其查询实现](https://dmfw.mca.gov.cn/XzqhVersionPublish.html)

```python
import json
import sys
import time
from urllib.parse import urlencode
from urllib.request import Request, urlopen

url = "https://dmfw.mca.gov.cn/xzqh/getCodeList"
params = dict(tableName="Xzqh20251231", parentCode="", placeCode="",
              title="", type="", pageNum=1, pageSize=1000)
rows = []
total = None
while True:
    request = Request(url, data=urlencode(params).encode())
    with urlopen(request, timeout=30) as response:
        result = json.load(response)
    if result.get("status") != 200:
        raise RuntimeError(f"查询失败，页码 {params['pageNum']}")
    if total is None:
        total = int(result["total"])
    batch = result.get("data")
    if int(result["total"]) != total or not isinstance(batch, list):
        raise ValueError("总数变化或分页数据缺失")
    if len(batch) != min(params["pageSize"], total - len(rows)):
        raise ValueError(f"分页条数异常，页码 {params['pageNum']}")
    rows.extend(batch)
    if len(rows) == total:
        break
    params["pageNum"] += 1
    time.sleep(0.3)

if total != 41935 or len({row["code"] for row in rows}) != total:
    raise ValueError("与 2025-12-31 快照的条数或唯一性不符")
json.dump(rows, sys.stdout, ensure_ascii=False)
```

## 实测结果和字段处理

| 项目 | 2025-12-31 快照 |
|---|---:|
| 省级记录 | 34 |
| 地级记录 | 333 |
| 县级记录 | 2,845 |
| 乡级记录 | 38,723 |
| 总记录 | 41,935 |
| 含数字代码的记录 | 41,934 |

接口的台湾省记录将 `code` 写为“资料暂缺”，可保留名称、将业务代码设为空并保留原值。其余 41,934 个代码均为九位数字且互异。原始 `parentCode` 为十二位；本快照中，所有非省级记录的父码取前九位均能匹配返回的 `code`。按父码建树可处理北京市直接下辖区等情况。保留字符串原值和 `level`，对外展示时省、地、县取六位，乡取九位。[国家地名信息库发布页](https://dmfw.mca.gov.cn/XzqhVersionPublish.html) · [行政区划代码管理办法](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202512/t20251204_528920.html)

## 从指定的政务服务页面取数

页面脚本提供 `xzqhApi.children('')` 读取省级根节点（实测 34 条），`xzqhApi.children(parentCode)` 读取直接下级。沿页面返回的十二位 `areacode` 查询，`hasChildren` 为真时继续，`displaycode` 是展示码。北京查询返回 16 个区，东城区返回 17 个街道；东华门街道的查询码为 `110101001000`，展示码为 `110101001`。[页面接口封装](https://zwfw.mca.gov.cn/appsv2/xzqhcx/js/xzqh-api.js)

也可在该页面上下文调用 `await xzqhApi.query('110000000000', '2', 1, 10)`。实测返回 `total = 1`，展开 `rows[0].children` 并递归遍历，共有北京市 1 条、区 16 条、乡级 343 条。这里的 total 只统计顶层匹配。按省调用时要逐层展开、核对各省完整性；本次全国全量验证走的是国家地名信息库的平铺分页接口。查询封装会在部分错误情况下返回空列表，单独的空结果不能证明已经取完。[详情页](https://zwfw.mca.gov.cn/appsv2/xzqhcx/detail.html?searchStr=110000000000&searchType=2) · [接口封装](https://zwfw.mca.gov.cn/appsv2/xzqhcx/js/xzqh-api.js)

## 年中更新与村级需求

民政部每年 1 月发布上一年末全国数据，各省级民政部门每年 1 月、7 月发布截至上月末的本地区乡级信息。如果业务需要 2026 年中的变更，应将各省公告作为带截止日期的更新单独管理。北京已发布截至 2026-06-30 的名录。[管理办法第十六条](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202512/t20251204_528920.html) · [北京市民政局年中代码表](https://mzj.beijing.gov.cn/art/2026/7/16/art_9984_692516.html)

全国快照止于乡级。村委会、居委会涉及另一套统计用区划代码。国家统计局明确，自 2024 年 10 月起停止公开具体相关代码；其历史答复提到 2023 年版本。未核实当前有公开的全国村级整库下载渠道，也不能通过将乡级代码补零推导各村代码。[国家统计局公开口径](https://www.stats.gov.cn/hd/lyzx/zxgk/202509/t20250903_1960996.html) · [2023 年历史版本说明](https://www.stats.gov.cn/hd/lyzx/zxgk/202312/t20231206_1945208.html)
